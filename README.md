# Revenue & Subscription Metrics Analysis
This repository contains a full-cycle data analysis project, from raw data processing to a final interactive dashboard and business presentation. The project focuses on tracking key performance indicators (KPIs) for a subscription-based (SaaS) model over 10 months.

## Repository Structure

[SQL_Scripts](https://github.com/OlhaHaidash/revenue_metrics/blob/main/revenue_metrics_code.sql.sql): Contains the source code used for data extraction, cleaning, and calculating core business metrics (MRR, Churn Rate, ARPPU). 

[Dashboard](https://public.tableau.com/app/profile/olha.haidash/viz/revenue_metrics_p2/RevenueMetrics): The visual representation of the analysis (Tableau), focusing on revenue dynamics and user portrait. 

[Presentation](https://github.com/OlhaHaidash/revenue_metrics/blob/main/GoIT_Revenue_Metrics_Project.pptx): A slide deck (PPTX) summarizing business insights and strategic recommendations.

[Video](https://youtu.be/kL9yO45CGKs): A recorded walkthrough of the dashboard and a summary of the project findings.
